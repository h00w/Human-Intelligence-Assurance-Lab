# Independent Human Semantic Calibration Protocol

Phase 1 does not allow a model judge to certify itself. The semantic judge remains **shadow-only** until this protocol passes.

## Release requirements

- at least **20 resolved samples**;
- at least **2 independent human reviewers per sample**;
- reviewer identity/provenance recorded for every label;
- disagreements require explicit adjudication rather than silent majority fabrication;
- inter-reviewer Cohen's kappa **>= 0.70**;
- judge-vs-human Cohen's kappa **>= 0.70**;
- critical human-failure recall **>= 0.95**.

## Reviewer workflow

1. Freeze the semantic human-review queue generated by the semantic-shadow workflow.
2. Generate reviewer files with `python scripts/prepare_human_calibration_package.py` or download them from the Human Calibration dashboard.
3. Give Reviewer A and Reviewer B the same frozen response set and rubric. Reviewer sheets **must not expose `judge_pass` or `judge_overall`**, and neither reviewer may see the other's labels before completion.
4. Each reviewer records `human_pass` and optional notes for every sample. Reviewer identity/provenance is fixed in the sheet.
5. Import both completed sheets with `python scripts/import_human_calibration_reviews.py reviewer_A.csv reviewer_B.csv`.
6. The importer verifies exact frozen-batch coverage and rejects missing labels, modified candidate responses, unknown samples, duplicate sample rows, and reused reviewer identities.
7. For disagreements, complete the generated `adjudication_queue.csv` with an explicit human `adjudicator_id` and `adjudicated_pass`, then rerun the importer with `--adjudication`.
8. Run `scripts/score_human_calibration.py` only against the validated merged labels.
9. Publish `runs/calibration_report.json` only from explicit human labels. Never synthesize, infer, or silently skip missing judgments.

The scorer accepts either `reviewer_id` or the legacy `reviewer` column, but incomplete rows now fail closed rather than being omitted from calibration. A single reviewer cannot unlock release-critical semantic judging.

See `docs/HUMAN_CALIBRATION_EXECUTION.md` for the complete operational runbook.
